# Estonian installer translation

`Estonian.isl` is the unofficial Inno Setup translation by LiivaneLord, based on the translation by tudiludi. It is copied unchanged from the [Inno Setup translations repository](https://github.com/jrsoftware/issrc/blob/main/Files/Languages/Unofficial/Estonian.isl). The original copyright and translator notices remain in the file.

English messages from the installed Inno Setup version provide fallback text for any newer setup messages absent from this translation.
